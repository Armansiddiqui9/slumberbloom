# Run it
`./run.sh` (Mac/Linux) or `run.bat` (Windows) → open http://localhost:8000
- `/` website (desktop) · `/m` website (mobile) · `/app/onboarding` · `/app/bedtime` · `/app/morning-dew` · `/app/garden` (auto desktop/mobile layout)
- `/play/` working game demo (Tuck in → +8h → Claim → Dawn → Lantern) · `/docs` API explorer
- Mockups keep their Google-hosted images, so they need internet. Rebuild pages after editing design/mockups: `python scripts/build_site.py`
